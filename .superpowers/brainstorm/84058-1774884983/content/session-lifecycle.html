Session States

DRAFT

Working on regex and/or LLM config. Not yet reviewed. Can edit freely.

REVIEWING

LLM has run on sample. Clinician is judging results. Can still tweak and re-run.

COMMITTED

Locked. Full pipeline running on corpus. Regex + prompt frozen.

DISCARDED

Thrown away. Kept for history only. One click to discard, no confirmation.

Key Rules

  • Only one active (DRAFT/REVIEWING) session at a time per project
  • "+ New Session" discards any current draft automatically (or prompts if it has LLM results)
  • Discard is instant — no "are you sure?" modal
  • Commit locks the session and triggers the full corpus run
  • A new session can optionally clone regex + prompt from a previous session as starting point
