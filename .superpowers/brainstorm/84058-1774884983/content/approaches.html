Unified Evaluation Session: Approaches

How to structure the regex + LLM + review flow within a single session

A

Wizard Steps (Linear)

Three sequential steps: 1) Regex Filters → 2) LLM Prompt → 3) Review & Commit

Each step is a full-screen view. "Next" / "Back" navigation. Clinician must complete regex before configuring LLM, must run LLM before reviewing.

Pros

  • Clear progression, hard to get lost
  • Enforces the "filter first, classify second" mental model
  • Simple to discard and restart

Cons

  • Can't glance at regex stats while reviewing LLM results
  • Going back to tweak regex requires navigating steps
  • Feels heavy if you just want to change one pattern
B

Single Page with Sections (Scrollable)

One long page with collapsible sections: Regex Filters (with live funnel) → LLM Config → Results & Review → Commit

Everything visible at once. Sections expand/collapse. The funnel stats bar is always pinned at the top.

Pros

  • Full context always visible — regex stats + LLM results on same page
  • Quick iteration: tweak regex, re-run, see impact without navigation
  • Feels lightweight and fast

Cons

  • Can get long with many results to review
  • Needs careful visual hierarchy to avoid overwhelm
  • Must manage state carefully (what's stale after regex change?)
C

Hybrid: Tabs within Session

Session page with tabs: Regex | LLM | Review | Summary. A persistent status bar at top shows the funnel: patients → regex match → LLM positive.

Tabs are always accessible (no forced progression), but LLM tab shows "configure regex first" if no patterns exist.

Pros

  • Clean separation without losing context (status bar always visible)
  • Jump between regex and review freely
  • Each tab stays focused — no scroll overwhelm
  • Easy to add more tabs later (e.g., Cost Estimate)

Cons

  • Slightly more complex than single page
  • Tab state management (stale indicators when regex changes)

My recommendation: Option B (Single Page) — keeps the clinician in flow, everything visible, fast iteration. The funnel bar pins to top as they scroll.
