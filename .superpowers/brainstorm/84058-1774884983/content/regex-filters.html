How It Works

  • Session starts by auto-sampling 100 patients or 10% of project (whichever is higher)
  • Each regex runs against all notes in the sample — counts update after each pattern add/edit/delete
  • Include patterns (blue): notes matching ANY include pattern are kept (OR logic)
  • Exclude patterns (red): notes matching ANY exclude pattern are removed, even if they matched an include
  • Per-pattern stats show how many notes/patients each pattern catches individually
  • "Suggest Patterns" button: sends event name + description to LLM, returns suggested patterns that the clinician can accept/edit/reject one by one
  • The funnel bar at top updates live as patterns change — always shows filter % and estimated LLM cost
