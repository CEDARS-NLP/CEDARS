Query Syntax (What Clinicians Write)

troponin OR MI Match notes containing either term
(ECG OR EKG) AND elevation Both conditions must match in the same note
embol* Wildcard: matches embolism, emboli, embolus, etc.
!suspected Exclude notes containing this term
(DVT OR PE) AND !suspected Combined: match DVT/PE but exclude if suspected

Under the Hood

  • Queries are parsed into spaCy Matcher patterns (case-insensitive token matching)
  • Wildcards (*, ?) converted to regex patterns internally
  • Built-in negation detection: even without ! exclusions, spaCy detects negated contexts ("no troponin elevation" won't match)
  • Multiple queries are OR'd together — a note matching any query is included
  • Exclude queries subtract from the result set
