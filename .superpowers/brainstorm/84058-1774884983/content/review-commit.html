Review & Commit Flow

  • Patient cards: expanded for positives (show reasoning + evidence), collapsed for negatives (one-line summary)
  • Clinician judges: Correct / Wrong / Skip + can override the event date
  • Live metrics update as reviews come in — no need to review all patients
  • Clinician can go back to edit search queries or LLM prompt and re-run at any point
  • Re-running LLM clears previous results but preserves search matches and reviews
  • Commit: locks everything, shows full corpus cost estimate, triggers pipeline on all patients
  • No new evaluation sessions allowed while a committed pipeline is running
