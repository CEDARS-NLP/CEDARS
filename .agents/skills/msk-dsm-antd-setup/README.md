# msk-dsm-antd-setup Skill

The `msk-dsm-antd-setup` skill configures the MSKCC Design System (DSM) in a web project using Ant Design as the component library. It integrates Ant Design (`antd`) with MSK brand theming via `@mskcc/theme-antd`, MSK design tokens via `@mskcc/tokens`, and optionally Tailwind 4, `@mskcc/fundamentals`, and `@mskcc/themes`. The skill detects the project's framework (Next.js App Router, Next.js Pages Router, Vite, or CRA) and package manager, installs the required packages, adds the correct CSS imports to the global stylesheet, creates the `AntdProvider` component with `ConfigProvider` and the MSK theme, and registers the provider in the root layout. It always prompts for the app role (`consumer` for patient-facing or `pro` for provider/internal) and the preferred default theme (`light` or `dark`) before generating any configuration.
